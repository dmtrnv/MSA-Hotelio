Далее описаны изменения, сделанные в рамках решения задачи.

1. В качестве booking-service используется сервис из task2. В task4 перенесен только Dockerfile, код сервиса остался на своем месте. При сборке образа задаем контекст
2. Сделана доработка booking-service:
   - добавлена поддержка HTTP/1.1 параллельно с HTTP/2
   - добавлен endpoint /ping и, если включена фича через флаг, то добавляется endpoint /feature
3. Реализован helm chart:
   - пробы readiness, liveness
   - отдельные файлы для staging и prod values
4. Реализован gitlab ci: 
   - name, tag берется из values используя yq
   - для тестирования запускаем контейнер из собранного образа и проверяем curl /ping
   - загружаем образ в minikube используя minikube image load
   - после helm upgrade дожидаемся выкатки новой версии
